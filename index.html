How to use the spreadsheet with OrientDig

  1. Open the original listing. Start from the CAFANS product detail page. Copy the seller’s listing URL and check whether OrientDig can load it.
  2. Check the exact variant. Match the color and model. For a jacket or hoodie, compare chest width and sleeve length with a garment that fits you. For shoes, confirm whether the size chart uses foot length or insole length.
  3. Review warehouse QC if available. Compare the photos for your specific item with the ordered variant. Check size labels, color and visible damage while an exchange may still be possible.
  4. Compare shipping quotes for the same parcel. Use the same destination, packed dimensions and weight. Check what each quote includes before comparing the totals.

OrientDig spreadsheet FAQ

Which link should I paste into OrientDig?

Use the original seller listing URL from the CAFANS product detail page. Check that the loaded product and variant match your shortlist.

What does the estimated USD price cover?

It reflects the listed item price in US dollars. Check the current variant price, shipping and applicable fees before budgeting for the full order.

What is included in the CSV?

The CSV contains the currently displayed product IDs, names, categories, estimated USD item prices and CAFANS detail links. Open it in Excel or import it into Google Sheets.
